    Metrics¶

    SynOmicBench provides comprehensive metrics for evaluating synthetic omics data across three dimensions:

    1. Fidelity Metrics¶

    Measures how well synthetic data preserves statistical properties of the original data.

    Univariate Similarity¶

    • File: metrics/fidelity/UnivariateSimilarity.py
    • Metrics: Distribution matching, Kolmogorov-Smirnov test, Wasserstein distance

    Pairwise Similarity¶

    • File: metrics/fidelity/PairwiseSimilarity.py
    • Metrics: Correlation preservation, pairwise distance matching

    Bayesian Comparison¶

    • File: metrics/fidelity/BayesianComparison.py
    • Metrics: Bayesian estimation of similarity with uncertainty quantification

    Missing Value Similarity¶

    • File: metrics/fidelity/MissingValueSimilarity.py
    • Metrics: Missing value pattern preservation

    Visualization¶

    • File: metrics/fidelity/visualization.py
    • Features: Plotting utilities for fidelity comparison

    2. Narrow Utility Metrics¶

    Evaluates utility for specific downstream analysis tasks.

    Differential Gene Expression (DGE)¶

    • File: metrics/narrow_utility/DGE.py
    • Purpose: Assess if synthetic data preserves DGE patterns
    • Use case: Biomarker discovery analysis

    Gene Set Enrichment Analysis (GSEA)¶

    • File: metrics/narrow_utility/GSEA.py
    • Purpose: Evaluate pathway-level preservation
    • Use case: Pathway analysis validation

    Survival Analysis¶

    • File: metrics/narrow_utility/survival_analysis.py
    • Purpose: Test survival prediction utility
    • Use case: Clinical outcome prediction

    Predictive Modeling¶

    • File: metrics/narrow_utility/predictive_model_comp.py
    • Purpose: Compare predictive power across datasets
    • Use case: Machine learning model training

    3. Privacy Metrics¶

    Assesses re-identification risks in synthetic data.

    Singling Out Risk¶

    • Files:
    • FigurePrivacy/SinglingOutRisk_Uni.ipynb
    • FigurePrivacy/SinglingOutRisk_Multi.ipynb
    • Metrics: Ability to uniquely identify individuals

    Linkability¶

    • Files:
    • FigurePrivacy/Linkabiliy.ipynb
    • FigurePrivacy/linkability_evaluator.py
    • Metrics: Risk of linking records to original data

    Inference Risk¶

    • File: FigurePrivacy/Inference-Copy1.ipynb
    • Metrics: Risk of inferring sensitive attributes

    Usage Example¶

    from SynOmics.metrics.fidelity import UnivariateSimilarity, PairwiseSimilarity
from SynOmics.metrics.narrow_utility import DGE

# Calculate fidelity metrics
uni_sim = UnivariateSimilarity()
uni_score = uni_sim.compute(original_data, synthetic_data)

pair_sim = PairwiseSimilarity()
pair_score = pair_sim.compute(original_data, synthetic_data)

# Calculate narrow utility
dge = DGE()
dge_score = dge.compute(synthetic_data, ground_truth_pathways)

    Visualization¶

    The library includes visualization tools for comparing results across multiple synthesis methods:

    from SynOmics.metrics.fidelity.visualization import plot_comparison

plot_comparison(
    results_dict,
    metrics=['univariate', 'pairwise', 'bayesian'],
    output_dir='figures/'
)
